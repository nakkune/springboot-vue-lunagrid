LunaGrid 개발자 가이드 & 라이브 예제

각 섹션별로 상세 설명, 표준 소스 코드, 실제로 구동되는 라이브 데이터 그리드를 함께 제공합니다. 아래의 그리드들을 직접 조작해보세요.

1. 듀얼 아키텍처 & 기본 그리드 생성

LunaGrid는 LunaDataAdapter(데이터 관리 계층)와 GridView(DOM 렌더링 계층)이 분리되어 있어 대량의 데이터를 안정적으로 다룹니다.

라이브 동작 그리드: 기본 데이터 바인딩
JavaScript 
// 1. DataAdapter & GridView 생성
const dataAdapter = new LunaDataAdapter();
const grid = new LunaGrid('#grid-container', {
  title: '임직원 기초 명부',
  dataAdapter: dataAdapter,
  theme: 'dark',
  columns: [
    { name: 'id', fieldName: 'id', header: { text: '사번' }, width: 80, align: 'center' },
    { name: 'name', fieldName: 'name', header: { text: '성명' }, width: 120, align: 'center' },
    { name: 'dept', fieldName: 'dept', header: { text: '부서' }, width: 140 },
    { name: 'role', fieldName: 'role', header: { text: '직급' }, width: 110, align: 'center' },
    { name: 'salary', fieldName: 'salary', header: { text: '급여' }, width: 130, align: 'right', formatter: 'currency' }
  ]
});

// 2. 데이터 주입
dataAdapter.setRows([
  { id: 'EMP-101', name: '김민준', dept: '플랫폼코어팀', role: '수석연구원', salary: 78000000 },
  { id: 'EMP-102', name: '이서연', dept: 'AI엔지니어링', role: '책임연구원', salary: 85000000 },
  { id: 'EMP-103', name: '박도현', dept: '클라우드인프라', role: '선임연구원', salary: 62000000 }
]);

2. 3대 컨트롤 바 (Indicator, StateBar, CheckBar)

행 순번(No.), 실시간 C/U/D 데이터 변경 상태(State), 다중 선택 체크박스(Check)를 그리드 좌측에 통합 렌더링합니다.

라이브 동작 그리드: 상태바 & 체크바
JavaScript Options 
const grid = new LunaGrid('#grid-bars', {
  dataAdapter: dataAdapter,
  indicator: { visible: true, label: 'No.', width: 45 },
  stateBar:  { visible: true, label: '상태', width: 45 }, // C(생성), U(수정), D(삭제) 자동 추적
  checkBar:  { visible: true, multiSelect: true, width: 40 },
  columns: [ ... ]
});

3. 7대 풍부한 컬럼 렌더러 (Column Renderers)

프로그레스 바, 상태 펄스 뱃지, 별점 평가, 미니 SVG 스파크라인 차트, 원형 아바타를 셀 내에 완벽하게 렌더링합니다.

라이브 동작 그리드: 시각화 렌더러 컬렉션
Column Definition 
columns: [
  { name: 'avatar', renderer: 'avatar', width: 100, align: 'center' },
  { name: 'project', header: { text: '프로젝트명' }, width: 160 },
  { name: 'progress', renderer: { type: 'progress', min: 0, max: 100, showLabel: true }, width: 140 },
  { name: 'status', renderer: { type: 'badge', colorMap: { '정상': 'success', '지연': 'danger' } }, width: 100, align: 'center' },
  { name: 'rating', renderer: { type: 'rating', max: 5 }, width: 120, align: 'center' },
  { name: 'trend', renderer: { type: 'sparkline', color: '#38bdf8' }, width: 120, align: 'center' }
];

4. 인라인 에디터 (Inline Editors)

더블 클릭으로 셀 편집 모드에 진입합니다. 날짜 피커(DatePicker), 숫자 스핀(NumberSpin), 자동완성(AutoComplete), 셀렉트 드롭다운을 지원합니다.

라이브 동작 그리드: 더블 클릭하여 편집해보세요
Editors Configuration 
columns: [
  { name: 'client', editor: { type: 'autoComplete', candidates: ['삼성전자', 'LG전자', '현대자동차', '네이버'] } },
  { name: 'category', editor: { type: 'select', options: ['서버/인프라', '소프트웨어', '클라우드'] } },
  { name: 'orderDate', editor: { type: 'datePicker', format: 'yyyy-MM-dd' } },
  { name: 'qty', type: 'number', editor: { type: 'numberSpin', min: 1, max: 100 } }
];

5. 계산 필드 (Calculated Field & Expressions)

수량이나 단가를 수정하면 valueExpression 및 valueCallback을 통해 공급가액과 최종 결제액이 실시간 자동 연산됩니다.

라이브 동작 그리드: 수량/단가 변경 시 실시간 자동 계산
Calculated Columns 
columns: [
  { name: 'qty', type: 'number', editor: 'numberSpin' },
  { name: 'unitPrice', type: 'number', formatter: 'currency' },
  // 1. 수식 표현식
  { name: 'supplyAmount', valueExpression: 'qty * unitPrice', formatter: 'currency' },
  // 2. 함수 콜백 (할인율 적용)
  { name: 'finalAmount', valueCallback: (r) => (r.qty * r.unitPrice) * (1 - (r.discount || 0) / 100), formatter: 'currency' }
];

6. 드래그 앤 드롭 행 그룹핑 & 소계 (Grouping)

상단 패널로 컬럼 헤더를 끌어다 놓아 다단계 그룹핑을 수행하고 그룹별 소계(Subtotal)를 자동으로 산출합니다.

라이브 동작 그리드: 부서별 그룹핑 & 소계
Grouping Config 
const grid = new LunaGrid('#grid-grouping', {
  dataAdapter: dataAdapter,
  rowGrouping: {
    enabled: true,
    showGroupPanel: true,
    groupSummary: true
  },
  columns: [ ... ]
});
grid.groupBy(['dept']);

12. LunaDataAdapter 핵심 API 명세

단일 데이터 모델 계층으로 CRUD, 변경 상태(RowState) 추적, 계산 필드, Undo/Redo, 데이터 I/O를 전담합니다.

메서드 파라미터 설명
setFields(fields) Array<FieldDef> 필드 스키마 및 계산 필드(수식/콜백/서브타입) 정의
setRows(rows, startRow) Array<object>, number 전체 데이터 행 주입 또는 Lazy Loading 부분 청크 업데이트
getRows(startRow, endRow) number, number 행 데이터 배열 조회 (지정 범위)
getRowCount() - 전체 행 개수 반환
addRow(row, position) object, 'top'|'bottom' 신규 행 추가 (상태: CREATED, Undo 지원)
insertRow(index, row) number, object 특정 위치에 행 삽입 (상태: CREATED, Undo 지원)
updateRow(rowIdOrIndex, values) string|number, object 행 데이터 수정 (상태: UPDATED, diff 감지 및 Undo 지원)
removeRow(rowIdOrIndex) string|number 행 삭제 (상태: DELETED, softDeleting 및 Undo 지원)
getValue(rowIdOrIndex, fieldName) string|number, string 단일 셀 값 조회 (계산 필드 및 Dot Notation 지원)
setValue(rowIdOrIndex, fieldName, val) string|number, string, any 단일 셀 값 수정
getJsonRow(rowIdOrIndex) string|number 계산 필드가 적용된 완본 JSON 행 조회
commit() - 모든 C/U/D 변경 사항 영구 확정 (RowState -> 'none')
rollback() - 직전 Commit 시점으로 전체 데이터 원상 복구
undo() / redo() - 데이터 변경 작업 실행 취소 및 다시 실행
getStateRows(state) 'created'|'updated'|'deleted' 상태별 행 데이터 목록 조회
fillJsonData(data, options) Array<object>, object JSON 데이터 모드별 적재 (set, append, insert, update)
fillCsvData(csvText, options) string, object CSV 텍스트 파싱 및 고속 데이터 적재
fillXmlData(xmlData, options) string|XMLDoc, object XML 문자열 또는 DOM 파싱 및 데이터 적재

13. TreeLunaDataAdapter 핵심 API 명세

계층형 트리 데이터 모델로 부모-자식 관계 관리, 노드 펼침/접힘, 서브노드 롤업 집계를 지원합니다.

메서드 파라미터 설명
setTreeRows(treeData) Array<TreeItem> children 계층 객체 배열 주입 및 평탄화
getRootCount() / getRoots() - 최상위 루트 노드 개수 및 목록 조회
getParent(nodeId) string|number 해당 노드의 부모 노드 ID 조회
getChildren(nodeId) string|number 해당 노드의 직계 자식 노드 ID 목록 반환
getDescendants(nodeId) string|number 해당 노드의 모든 하위 자손 노드 ID 목록 반환
isLeaf(nodeId) string|number 리프(말단) 노드 여부 확인
expand(nodeId) / collapse(nodeId) string|number 특정 트리 노드 펼침 및 접힘
expandAll() / collapseAll() - 전체 계층 트리 일괄 펼침 및 접힘
calcSubnodeSummary(summaryDefs) object 하위 자식 노드 필드값(합계/평균/최대/최소)을 부모로 상향 롤업 집계

14. GridView (LunaGrid) 핵심 API 명세

UI 렌더링, 뷰 가상화, 엑셀 필터링, 정렬, 그룹핑, 클립보드 및 7종 Export를 제어합니다.

메서드 파라미터 설명
setDataAdapter(adapter) LunaDataAdapter 그리드에 연결할 DataAdapter 인스턴스 교체 및 바인딩
getDataAdapter() - 현재 바인딩된 DataAdapter 인스턴스 반환
setColumns(columns) Array<ColumnDef> 그리드 컬럼 레이아웃, 너비, 렌더러, 에디터 재구성
refresh() - 그리드 전체 뷰 및 가상 스크롤 영역 재렌더링
setTheme(themeName) 'dark'|'light'|'classic'|'blue' 실시간 CSS 테마 변경
groupBy(fieldNames) Array<string> 특정 컬럼 기준 다단계 행 그룹핑 및 소계 렌더링
setFilter(fieldName, filterFn) string, function 특정 컬럼에 커스텀 필터 조건 적용
setSorting(fieldName, direction) string, 'asc'|'desc' 다중 정렬 적용 및 헤더 인디케이터 표시
exportToExcel(filename) string 스타일이 보존된 Excel (.xlsx / XML) 파일 내보내기
exportToCsv(filename) string BOM UTF-8 인코딩 지원 CSV 파일 내보내기
exportToJson(filename, options) string, object 그리드 현재 뷰 또는 원본 JSON 내보내기
메시지가 표시됩니다.
